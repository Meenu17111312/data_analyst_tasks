# Task 1 – Data Cleaning & Preprocessing

# Objective
Clean and prepare a raw dataset by handling missing values, duplicates, inconsistent formats, and data types.

# Dataset
Mall_Customers.csv (Kaggle)

# Steps Performed
1. Checked for missing values and duplicates.
2. Removed duplicate rows.
3. Filled missing values using median/mean.
4. Standardized text values (Gender).
5. Renamed columns (lowercase, underscores).
6. Verified data types and saved cleaned dataset.

 # Deliverables
cleaned_data.csv – cleaned dataset  
task1_cleaning.ipynb – notebook  
README.md – summary
